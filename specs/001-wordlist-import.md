# S-001 词表导入（3000+ 词族）

状态：**done**　依赖：D2（双库分层）、D6（稳定 id）

## 背景 / 问题

`lib/data/seed-words.ts` 只内置了 90 个词族。阶段 1 的全部价值在于把 K1–K3 共 3000 词族
铺满（覆盖率 85% → 93%）。手工维护 3000 条 TS 常量不可行，且**必须保证换词表不破坏任何人的进度**。

## 目标

1. 能从外部词表文件导入 3000+ 词族到共享词库
2. 重复导入**幂等**：不产生重复卡片、不重置任何人的复习状态
3. 释义允许后补（导入时可为空，交给 S-002）

## 非目标

- 不在本 spec 内生成释义（S-002）
- 不内置受版权限制的词表文件；只提供格式与导入通道

## 输入格式

纯文本，每行一条，**制表符或逗号分隔**，字段按位置解析：

```
word                      # 仅词形 → rank 按行号，释义留空
word <TAB> rank           # 指定排名
word <TAB> rank <TAB> 释义  # 附带中文释义（可选）
```

- 空行、以 `#` 开头的行忽略
- 词形统一小写、去空白；重复词形只保留**排名最小**的一条

## 频率分档（Nation 口径）

| rank | freqBand |
| --- | --- |
| ≤ 1000 | K1 |
| ≤ 2000 | K2 |
| ≤ 3000 | K3 |
| ≤ 5000 | K4-5 |
| ≤ 9000 | K6-9 |
| 其余 | off |

CEFR 粗估：≤500 A1 / ≤1200 A2 / ≤2500 B1 / ≤5000 B2 / 其余 C1。

## 实现要点

1. **id 推导必须稳定**（D6）：
   - 词族 `fam.<lemma>`、词条 `w.<lemma>`、义项 `w.<lemma>.s1`
   - 卡片 `w.<lemma>:rec`（识别）、`w.<lemma>:prod`（产出）
   - lemma 中的空格替换为 `_`
2. 写入共享库 `elm-shared`，**不触碰**任何 `elm-<userId>`
3. 卡片 `interleaveGroup = index % 7`，与 seed 一致
4. 导入后按频段重算路径节点 `targetFamilyIds`：
   - `s1-k1a` ≤1000 的前 60% / `s1-k1b` ≤1000 的后 40%
   - `s1-k2` = K2、`s1-k3` = K3、`s3-academic` = K4-5 及以后
   - 同一节点超过 400 个词族时按 rank 截断，避免单节点进度分母过大
5. 已存在的词族：只更新 `freqRank / freqBand / cefr`，**保留**已有 `members`、不重建卡片
6. 单词卡在没有释义时：`definitionStatus = 'pending'`，`definitionEn = ''`

## 验收标准

1. 导入含 3000 行的文本后，`elm-shared` 的 `wordFamilies` 计数 ≥ 3000
2. 卡片总数 = 词条数 × 2
3. 再次导入同一份文本：**卡片数与词族数不变**（幂等）
4. 导入不会改变任何 `elm-<userId>` 的 `reviewStates`（导出前后逐条比对）
5. 导入后路径节点的 `targetFamilyIds` 非空且不重复
6. `tsc --noEmit` 与 `next build` 通过，浏览器控制台零错误
7. 导入 3000 词耗时 < 5s

### 已知限制

- 导入的词默认 `definitionStatus = 'pending'`，释义为占位文案，等待 S-002 补全
- 单个路径节点上限 400 个词族（`NODE_FAMILY_CAP`），K2/K3 实际各有 1000 个词族被截断
  → 需要时按 rank 分批解锁，属于后续 spec
- **重复导入会按新值更新已有词族的 `freqRank`**（这是设计意图，便于整体替换词表）。
  副作用：**局部导入**（例如只粘贴几行）会把这几行强行排到最前，打乱词频顺序与路径挂载。
  - 实例：验收脚本一度用 `about<TAB>1` 导入，把 `about` 的 rank 改成 1，导致它排到 `the` 前面，
    并让依赖"按频率取第一个"的逻辑全部错位
  - 规避：整体替换词表，或局部导入时沿用原 rank
  - 后续可考虑：导入前给出"这会改变 N 个已有词的排名"的确认提示
