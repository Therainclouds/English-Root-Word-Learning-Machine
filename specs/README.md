## 已落定的决策（不再讨论）

| 编号 | 决策 | 理由 / 边界 |
| --- | --- | --- |
| D1 | **纯前端本地单机**，多人共用一台电脑 | 多设备 / 多人远程**不在范围内**，需要后端，另开 spec（S-006 暂缓） |
| D2 | 数据双库分层：`elm-shared`（内容）/ `elm-<userId>`（状态） | 换词表不影响任何人的进度（已实现） |
| D3 | 配置分层：LLM / 决策模型**全局共享**；学习参数（每日新词上限、保持率、显示中文）**每人独立** | 快慢有别（已实现） |
| D4 | **判断由确定性代码负责**（排程 FSRS-6、掌握度、解锁、覆盖率）；LLM 只生成内容 | 可复现、可审计 |
| D5 | 决策模型（千问 decision-model-preview）**只输出信号**，低置信度回退，不直接改排程 | 不生成文本 |
| D6 | 卡片 id 与词族 id 必须**稳定可推导**（`fam.<lemma>` / `w.<lemma>` / `<wordId>:rec` / `:prod`） | 保证重复导入不产生重复卡、进度不丢 |
| D7 | 中文释义保留但**不作为唯一考点**；释义语言可切换 | 减少母语中介 |
| D8 | 词根词缀模块 = **阶段 3 选修**，不进阶段 1 主路径 | 证据：对高频口语词无效 |
| D9 | 学习参数默认：每日新词 15、目标保持率 0.9 | 超出会产生不可承受的复习债 |
| D10 | 形态切分**离线落库**（种子常量 + 构建期 ETL），运行期不调 LLM 做拆解；LLM 只补 `mnemonic` / `literalGlue` 并写回共享库复用 | 同一词素在不同词里必须一致；运行期每词一调用在成本与延迟上不可接受 |
| D11 | 词根卡片走**阶段 3 独立路径节点 + 独立每日预算**，不占用阶段 1 的 `dailyNewLimit` | 避免词根卡挤兑高频词，防止复习债爆炸 |
| D12 | 学习页**必须在页面上作答**，系统客观判定（选择题命中答案集 / 输入完全一致）；答错记 lapse(0)、答对记良好(4)，**取消主观自评** | 自评会"事后合理化"（产出卡尤其严重：没地方证明自己想过什么）；判定必须确定性、可复现、可审计（D4） |
| D13 | 主题（浅色 / 深色 / 跟随系统）与所有交互控件统一走 **shadcn + Radix** 组件（`components/ui`），不手写原生 `input[type=range]` / `select` | 深色硬编码导致观感压抑、不利于长时间阅读；原生控件在触屏与小屏上不可用、也不符合现代交互预期 |
| D14 | 排程引擎改用 **FSRS-6**（`ts-fsrs`，MIT），参数用官方默认值（在约 17 亿条真实复习记录上训练），**不做个人参数优化** | 官方基准：默认参数 log loss 0.3620 vs 个人优化后 0.3460，差距仅 ~4.4%——"等攒够记录再换"不成立；自建优化器需要 ≥1000 条记录且与客观两档评分不可比 |
| D15 | 掌握判定口径由"0–1 启发式"改为 **FSRS 稳定度天数**（`minStabilityDays`，默认 21 天） | `stability` 在 FSRS 中即"R 衰减到 90% 所需天数"，比自造指标有物理意义；实测连续答对 2 次 S≈13.8、3 次 S≈57 天，21 天与旧口径强度相当 |
| D16 | 释义**优先由开源词典在构建期生成并内置**（ECDICT，命中 99.9%），大模型仅作可选增强 | 要求学习者先配好 API key 才能背单词，这个门槛不可接受；构建期生成 = 运行期零请求、零成本、无 CORS |

## 验收脚本

每个已完成的 spec 都有对应的真实运行时验收脚本（CDP 驱动浏览器，非单测）：

| 脚本 | 覆盖 |
| --- | --- |
| `scripts/verify-s001.mjs` | 词表导入 3000 词、幂等、不破坏进度 |
| `scripts/verify-s002.mjs` | 释义按需生成、写回共享库、降级 |
| `scripts/verify-s003.mjs` | 生词率 / 着色 / 加入学习 / 用户隔离 |
| `scripts/verify-s005.mjs` | 重试 / 缓存 / 不重试 / 用量记录（配 `scripts/mock-llm.mjs`） |
| `scripts/verify-legacy-word.mjs` | 无 `definitionStatus` 的旧数据不被覆盖 |
| `scripts/verify-morphemes.mjs` | 词根数据离线自检（15 项）：数据完整 / 引用完整 / 切分可复原 / 正例切出率 / 噪声零误切 / 误切黑名单 / 词根卡独立预算（D11）/ 判定不误伤正确答案 / **FSRS 排程与目标保持率 / 旧状态迁移 / 实际保持率统计** |
| `scripts/verify-s007.mjs` | 词根导入幂等、阶段 1 路径不受影响、交错分组、重新导入保留 LLM 讲解（16 项） |
| `scripts/verify-fsrs.mjs` | FSRS 落库字段、日志特征、首页实际保持率面板（6 项） |
| `scripts/verify-dict.mjs` | 内置释义数据可用、导入覆盖率 ≥95%、重复导入稳定（5 项） |
| `scripts/build-definitions.mjs` | 构建期从 ECDICT 生成内置释义（`node scripts/build-definitions.mjs`） |

前置：`npm run dev` 已启动，且 Edge/Chrome 以 `--remote-debugging-port=9222` 启动。
