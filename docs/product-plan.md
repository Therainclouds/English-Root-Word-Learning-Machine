# 产品方案：英语基础能力学习机

> 依据：`docs/learning-science.md`（方法论）· `docs/data-model.md`（数据结构）
> 学习目标由用户指定：① 掌握基本英语交流 ② 可视化学习路径 ③ 可接入大模型辅助。

---

## 1. 目标与重心

用户选定的学习重心：**词汇阅读基础优先**。

> 先堆 2000–3000 高频词族与阅读量，再转向听说输出。

这一选择与科学证据一致：
- 高频 1000 词族 ≈ 覆盖文本 85%，3000 词族 ≈ 93–95%（**收益最陡的一段**）
- 阅读是唯一可长期持续、且同时提供「语境 + 复现 + 附带习得」的输入源
- 词根词缀法对**日耳曼语源的口语高频词**（get / make / take / put / thing）几乎无效

**因此词根模块从"核心"降级为阶段 3 的进阶/选修分支**（详见 `docs/root-data-schema.md`）。

---

## 2. 三阶段学习路径

| 阶段 | 名称 | 目标 | 核心活动 | 达标判据 |
| --- | --- | --- | --- | --- |
| **阶段 1** | 词汇与阅读基建 | 2000–3000 高频词族 + 分级阅读 | SRS 词汇卡、分级短文（生词率 2%–5%）、窄读 | 标准文本覆盖率 ≥ 95% |
| **阶段 2** | 语法自动化与场景 | 句法程序化、语块整存整取 | 句型限时训练、4/3/2 复述、场景语块、LLM 对话陪练 | 限时句型正确率 ≥ 90% |
| **阶段 3** | 扩展与进阶 | 学术词汇、听说输出、词根系统 | 词根派生树、跟读 shadowing、自由输出 + LLM 纠错 | 覆盖率 ≥ 98%、能完成场景对话 |

阶段 1 是本 MVP 的实现范围；阶段 2/3 在路径图上**可见但默认锁定**。

## 3. 功能清单

### MVP（本次实现）

| 模块 | 功能 | 对应理论 |
| --- | --- | --- |
| **学习路径（Canvas）** | 有向依赖图：节点=单元，边=前置；状态（锁定/可学/学习中/待复习/已掌握）；进度与覆盖率仪表盘 | 可视化元认知、目标分解 |
| **词汇学习** | 高频词族卡片：分级英文释义 + 语境例句 + 搭配；双向卡片（识别 / 产出） | 频率优先、深度加工、双向提取 |
| **SRS 复习** | FSRS-6 排程（目标保持率可调）、每日新词上限、复习债预警、交错分组 | 间隔效应、提取练习、交错 |
| **分级阅读** | 短文自动计算生词率，按已知词族着色生词；点击生词查词并加入学习 | 可理解输入 i+1、附带习得 |
| **覆盖率仪表盘** | 已掌握词族在标准语料上的覆盖率、词汇量估计、学习热力图 | 量化反馈 |
| **LLM 助手** | 分级释义、多语境例句、搭配与语域解释、易混辨析、对话陪练 | 精细化加工、注意触发 |
| **设置** | LLM 供应商配置（OpenAI 兼容 / Anthropic / Ollama）、每日负荷、目标保持率 | 可插拔 |

### 后续（不在 MVP）

- 听力切分训练、跟读评分
- 4/3/2 复述计时器
- 词根派生树可视化（阶段 3）
- 数据导入/导出、跨设备同步

## 4. 技术架构

```
┌─────────────────────────────────────────────────┐
│  Next.js 15 (App Router, output: 'export')      │
│  全部 'use client'，无服务端依赖                 │
├─────────────────────────────────────────────────┤
│  UI 层    Magic UI + Tailwind CSS + Framer Motion │
│           学习路径用原生 Canvas 2D 绘制           │
├─────────────────────────────────────────────────┤
│  逻辑层   srs.ts (FSRS-6)  ·  coverage.ts        │
│           path.ts (依赖图推进)                    │
├─────────────────────────────────────────────────┤
│  数据层   IndexedDB (idb)  ·  words / reviews /  │
│           passages / settings / pathState        │
├─────────────────────────────────────────────────┤
│  LLM 层   可插拔适配器 LlmProvider 接口           │
│           OpenAICompatible / Anthropic / Ollama  │
└─────────────────────────────────────────────────┘
```

### 关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 部署形态 | 静态导出（`output: 'export'`） | 符合"纯前端本地应用"，可直接开文件/`serve` 运行 |
| 数据存储 | IndexedDB（via `idb`） | localStorage 容量不足，需存词表与复习流水 |
| 排程算法 | FSRS-6（`ts-fsrs`，MIT；官方默认参数 + 可调目标保持率） | 默认参数在约 17 亿条真实复习记录上训练；个人优化仅再提升约 4.4% |
| 路径可视化 | 原生 Canvas 2D | 用户指定 canvas；无额外依赖，可控动画 |
| 组件美观 | Magic UI（shadcn 生态，CLI 复制式） | 用户指定 |

## 5. LLM 职责边界（重要）

| ✅ LLM 负责 | ❌ LLM 不负责 |
| --- | --- |
| 分级释义（限定用 1500 词解释） | 复习排程（必须确定性算法） |
| 生成多个不同语境的例句 | 掌握度判定与节点解锁 |
| 搭配、语域、语用说明 | 覆盖率与统计计算 |
| 易混词辨析 | 数据持久化 |
| 对话陪练、表达纠错与改写 | 任何影响进度的状态写入 |

LLM 输出一律走**结构化 JSON + 运行时校验**，解析失败降级为模板内容，绝不阻塞学习流程。

## 6. 已知风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| **浏览器直连 CORS** | Anthropic 默认拒绝浏览器请求 | 适配器自动加 `anthropic-dangerous-direct-browser-access: true` |
| Ollama 跨域 | 本地请求被拒 | 文档提示启动 `OLLAMA_ORIGINS=*` |
| **密钥明文存本地** | 本机安全 | 设置页明确警示；支持留空（降级为无 LLM 模式） |
| 词表版权 | 合规 | 种子数据自研/开放许可，字段保留 `sources` |
| 复习债爆炸 | 用户流失 | 每日新词上限 + 债务预警 + 可调目标保持率 |
| 静态导出限制 | 无 SSR/API 路由 | 全量客户端化，`images.unoptimized` |

## 7. 里程碑

- **M1** 项目骨架 + 数据层 + 种子词表（约 300 高频词族示例）
- **M2** SRS 引擎 + 学习/复习界面
- **M3** Canvas 学习路径 + 覆盖率仪表盘
- **M4** 分级阅读器（生词率计算与着色）
- **M5** LLM 适配器与助手面板
- **M6** 阶段 2/3 内容扩展与词根模块接入
