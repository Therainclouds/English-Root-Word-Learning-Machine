# 语言学习的科学方法：系统性知识框架

> 用途：本项目（英语词根学习机）的方法论依据。
> 边界：本文件是研究与综述的整合笔记，结论标注证据强度；具体数字请回溯原始文献核对。

## 0. 总框架（5 层）

| 层 | 回答的问题 | 内容 |
| --- | --- | --- |
| 目标层 | "学会"指什么 | 词汇知识维度 × 技能维度（听/说/读/写）× 接受性 vs 产出性 |
| 理论层 | 为什么学会/学不会 | SLA 理论、认知心理学、词汇学、技能自动化、动机情感 |
| 原则层 | 不可违背的机制 | 输入、注意、提取、间隔、交错、深度加工 |
| 策略层 | 每天做什么 | SRS、泛读、窄读、词根树、句库、跟读、限时训练 |
| 反馈层 | 怎么知道有效 | 词汇量测试、文本覆盖率、流利度指标、错误率 |

绝大多数方法之争（语法先学 vs 语感、背单词 vs 阅读）其实是**在不同层讨论问题**，因此永远吵不清。

## 1. 目标层：先定义"学会了"

### 1.1 词汇知识的多维性（Nation）

一个词被"掌握"包含以下维度，每维都有接受性 / 产出性之分：

- **形式**：口语形式、书写形式、词形变化（屈折与派生）
- **意义**：概念义、联想义（搭配、语义场）
- **使用**：语法行为、搭配、语域、频率

结论："认识一个词"是**程度问题**，不是 0/1。

### 1.2 技能维度

听 / 说 / 读 / 写是四条**相对独立的通道**，词汇量增长不会自动跨通道迁移。
背单词 → 主要提升**阅读**；听说需要各自的输入/输出训练。

### 1.3 量化目标（覆盖率）

| 目标 | 需要的词族量 | 文本覆盖率 |
| --- | --- | --- |
| 能读简易读物 | ~1000–2000 | 85%–90% |
| 能读一般非虚构（门槛） | ~3000–5000 | 95% |
| 学术阅读舒适 | ~8000–9000 | 98% |

口语要求略低于书面。**95% 是可读门槛，98% 是舒适线**（Nation, 2006，基于 BNC）。

## 2. 理论层：五大支柱

### 2.1 二语习得（SLA）

| 理论 | 核心主张 | 对我们的启示 |
| --- | --- | --- |
| Krashen 监控模型 | 可理解输入（i+1）是习得的必要条件；"学得"的语法只作监控器；情感过滤 | 输入必须可理解，焦虑会阻断输入 |
| Swain 输出假说 | 输出有三大功能：注意触发、假设检验、元语言反思 | 必须做"被推动的输出"，不能只读 |
| Long 互动假说 | 意义协商让输入变得可理解；focus on form 优于 focus on forms | 形式要在意义交流中被注意 |
| Schmidt 注意假说 | 无注意即无习得：input → noticed input → intake | 解释了"磨耳朵"为何低效 |
| Selinker 中介语 | 学习者语言是独立系统，错误是发展性的 | 错误不是敌人，是信号 |
| 动态系统理论 | 发展非线性，存在高原期与倒退 | 不能按"学时 × 效率"线性估算 |

### 2.2 认知心理学（记忆的主战场）

- **遗忘曲线与间隔效应**（Ebbinghaus；Cepeda et al., 2006）
  复习间隔应随目标保持期增长，约为**目标保持期的 10%–20%**（想记 1 年 → 间隔 1–2 个月起步）。
- **测试效应 / 提取练习**（Roediger & Karpicke, 2006；Dunlosky et al., 2013 评为"高效用"）
  **主动回忆 >> 重复阅读**。重读制造"熟悉感错觉"。
- **合意困难**（Bjork）：间隔、交错、变异、生成让当下更慢，长期更好。
- **交错 vs 分块**：混合练习在长期保持与迁移上优于按类型集中练（数学/运动证据强，词汇证据中等）。
- **加工深度**（Craik & Lockhart）：语义加工 > 语音/字形加工；生成 > 阅读。
- **双重编码**（Paivio）：语言 + 图像走两条通道。
- **迁移适当加工**：练什么方式，就考出什么方式。阅读练出的词不一定能说出/写出。
- **工作记忆与认知负荷**（Baddeley；Sweller）：容量有限；自动化后释放容量——这解释了"听懂但说不出"。
- **睡眠巩固**： overnight 记忆重放对程序性与语音学习尤为关键。

### 2.3 词汇习得（Nation / Schmitt / Laufer 一系）

- **词频决定优先级**：先拿下 2000–3000 高频词族，覆盖率收益最大（Zipf 定律）。
- **学习负担（learning burden）**：一个词难记与否，取决于形音匹配、拼写透明度、形态规则性、语义复杂度、搭配、与母语距离。
- **附带习得**：泛读能附带学词，但单次遭遇习得率仅约 **5%–15%**，常需 **5–16 次不同语境遭遇**才牢固。泛读是长线资产，不能替代直接学习。
- **马太效应**：词汇量越大，附带习得越容易（已知词提供上下文锚点）。
- **形态意识（morphological awareness）**（Carlisle; Kieffer & Lesaux; Bowers et al.）
  对词根词缀的敏感度显著预测词汇量、阅读理解与学术词汇增长。
  **这是本项目所在的理论位置。**

### 2.4 技能自动化（Anderson ACT-R / DeKeyser）

陈述性知识 →（练习）→ 程序性知识 →（持续练习）→ 自动化。

关键：**知识 ≠ 技能**。知道规则与在实时压力下正确调用是两套东西。
流利度需要**限时、高成功率的重复练习**（Nation 的 fluency strand：4/3/2 复述、重复阅读、限时阅读）。

### 2.5 动机与情感

- **情感过滤**：焦虑高 → 输入被过滤。
- **自我决定理论**（自主性 / 胜任感 / 归属感）。
- **Dörnyei 二语动机自我系统**：能"看见未来使用这门语言的自己"的学习者坚持更久。
- **关键期**：语音与形态句法上"越早越好"的长期优势证据较强；成人在**初始速度、显性学习、元语言意识**上占优 → **成人不应模仿儿童路径**，应充分利用显性/分析优势。

## 3. 原则层：12 条可操作原则

1. **可理解输入优先**，难度"刚好难一点"（i+1）→ 生词率控制在 **2%–5%** 最经济。
2. **频率优先**：先掌握高频词族，覆盖率收益最大。
3. **注意是入口**：没有注意的加工是浪费，要设计"被迫注意"的任务。
4. **提取优于输入**：把时间从"再看一遍"移到"先想起来"。
5. **间隔复习**：按遗忘临界点安排，而非按天数平均分配。
6. **交错 + 变异**：同一词根/语法点在不同句子、语境、题型中出现。
7. **深度加工**：语义联想、词源故事、例句、对比、反义——加工越深记得越牢。
8. **形式—意义联结**：孤立背拼写/中文对译是最浅的加工，效果最差。
9. **语境化 + 去语境化交替**：语境给意义，抽离给速度（自动化必需）。
10. **接受性与产出性分开练**：能认 ≠ 能说；产出需要"意义 → 检索形式"的反向训练。
11. **限时练习练流利度**：4/3/2、重复朗读、跟读。
12. **低焦虑 + 高自主**：可理解、可选择、有成就感。

## 4. 策略层：常见策略与证据强度

| 策略 | 机制 | 证据强度 | 适用 |
| --- | --- | --- | --- |
| 间隔重复系统（SRS） | 间隔效应 + 提取练习 | **强** | 词汇、搭配、语法点 |
| 主动回忆 / 自测 | 测试效应 | **强** | 一切 |
| 泛读（extensive reading） | 高频复现 + 语境 | **强**（长期） | 中高频词、阅读流畅度 |
| 窄读 / 窄听 | 降低认知负荷，提高复现 | 中 | 学术 / 专业词汇 |
| 词根词缀 / 形态分析 | 深度加工 + 语义网络 | **中偏强**（对学术词、长词） | 3000 词以上的派生词 |
| 关键词法（keyword mnemonic） | 双重编码 + 精细化 | 中（短期强，长期易退化为字面义） | 初期难词，慎长期依赖 |
| 图像 / 双重编码 | 双通道 | 中 | 具体名词、动词 |
| 例句句库（sentence mining） | 语境 + 提取 | 中偏强 | 中高级词汇 |
| 跟读 / shadowing | 语音程序化 + 工作记忆 | 中（证据有限） | 听力切分、语调 |
| 刻意练习 + 即时反馈 | 程序化、纠错 | **强**（发音 / 语法准确度） | 口语、写作 |
| 限时流利度训练 | 自动化 | 中偏强 | 已知材料的提取速度 |
| 背景音"磨耳朵" | 无注意 → 几乎无效 | **弱 / 负** | 不推荐 |
| 纯语法规则背诵后套用 | 陈述性 ≠ 程序性 | 弱 | 只作监控器 |
| 多任务并行学 | 认知负荷超载 | **负** | 避免 |

### 常见误区

集中填鸭（考前突击）、重读笔记、抄写十遍、依赖"语感"而不测量、把"打卡天数"当习得量、过早追求口语流利度而牺牲准确度、长期依赖母语翻译法。

## 5. 效果与边界：量化现实

- **可预期收益**：0 → "能读一般非虚构文本"（覆盖率 95%+）约需 **2000–3000 词族 + 相应语法自动化**；学术舒适阅读需 **8000–9000 词族**。
- **时间尺度**：词汇是资产积累型。SRS + 泛读的可持续速率约**每天 10–20 个新词（含复习）**，可维持数年；短期冲量会导致复习债爆炸。
- **高原期是常态**，不是方法失效（动态系统的非线性）。
- **迁移有限**：背单词主要转化为阅读词汇量，**不自动转化为听力与口语**。
- **个体差异大**：工作记忆、语音短时记忆、动机、母语距离都会改变最优配方。

## 6. 对本项目（词根学习机）的硬约束

1. **定位要准**：词根法是**中高频之上的倍增器**，不是替代品。先确保用户掌握 2000 高频词族，词根才有语义网络可挂靠；高频功能词（the / of / get）词根法无效。
2. **双指标排序**：`词族频率 × 词根派生力`（该词根能派生的常用词数）决定教学优先级。
3. **强制深度加工**：词根 + 同源词树 + 对比/反义 + 至少一个语境例句，杜绝"词根 ↔ 中文义"的浅层对译。
4. **双向提取**：`词根 → 词`（产出方向）与 `词 → 词根/义`（识别方向）都要练。
5. **必须接 SRS**：间隔 + 提取是效果的决定性因素，无它则词根知识线性遗忘。
6. **交错呈现**：同一词根的词散布在不同批次，而非一次刷完 20 个 `-spect` 词。
7. **可测量**：核心指标用**文本覆盖率**（已学词族在标准文本中的占比），而非"学了多少个词根"。
8. **控制认知负荷**：一次呈现同源词不超过 **5–7 个**；例句生词率控制在 **2%–5%**。
